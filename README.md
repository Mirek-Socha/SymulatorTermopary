# Symulator Termopary

Aplikacja dydaktyczna do wirtualnego testowania kontaktowego pomiaru temperatury termoelementem (termoparą).

**Autor:** Mirosław Socha  
**Jednostka:** Katedra Metrologii i Elektroniki, WEAIiIB, AGH Akademia Górniczo-Hutnicza, Kraków  
**Wersja:** v1.1.0

## Uruchomienie

Jeden plik HTML, zero zależności lokalnych — otworzyć `SymulatorTermopary.html` w przeglądarce.

## Funkcje

- 6 typów termopar (K, J, T, E, N, S) z tablicami NIST ITS-90
- Tryb Podstawowy i Tryb Eksperta
- Kompensacja złącza zimnego (CJC)
- Model przetwornika A/C (10–24 bit)
- Obliczanie R_tc z geometrii przewodów
- Tło historyczne: ewolucja przyrządów (galwanometr 1875 → nowoczesny przetwornik)
- Budżet błędów metodą RSS
- Panel teorii z formułami KaTeX i bibliografią
